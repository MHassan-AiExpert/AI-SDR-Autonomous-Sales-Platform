# Luxury UI (Midnight & Brass) Implementation Plan

**Goal:** Restyle the web app in Midnight & Brass, with a dark/light switch, a grouped sidebar and a friendlier Overview, without changing any feature.

**Architecture:**
- **Theme and colour helpers:** pure functions for the theme cookie and the accent text colour live in `src/lib/theme.ts`.
- **Navigation:** the 20 workspace links are data in `src/lib/nav.ts`, rendered by a small client component that highlights the current page.
- **Shared styles:** `globals.css` carries both themes and every shared component style.
- **Theme switch:** `POST /theme` sets the cookie and redirects back, so it works without JavaScript.

**Tech Stack:** Next 16 App Router, React 19, plain CSS, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-17-luxury-ui-design.md`

## Global Constraints

- No route, database, server action or permission changes; all 20 workspace pages stay reachable at their current URLs.
- Default accent `#e0b878`; dark text on accent `#1a1408`, light text `#ffffff`, chosen by contrast.
- Fonts: Fraunces (headings, numbers), Plus Jakarta Sans (interface text), bundled via Fontsource with `font-display: swap`.
- Cookie name `theme`, values `dark` | `light`; anything else means follow the system.

## Review Focus

- An agency colour that is very light (for example `#f5f5f5`) must get dark button text.
- A tampered theme cookie (`theme=<script>`) must be ignored.
- `POST /theme` with an external `back` URL must not redirect off-site.
- Signed-out redirects for every workspace path must keep working (E2E-03).
- On narrow screens, the sidebar must not hide the page content.
